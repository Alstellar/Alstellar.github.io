Политика конфиденциальности Veles Helper

Дата последнего обновления: 21 августа 2026 года

Настоящая Политика конфиденциальности описывает, как браузерное расширение Veles Helper обрабатывает данные при использовании его функций.

Veles Helper не продаёт пользовательские данные, не использует их для рекламы и не передаёт их разработчику на собственные серверы.

1. Для чего предназначено расширение

Veles Helper помогает пользователю настраивать, запускать и анализировать бектесты торговых стратегий на платформе Veles Finance, работать с результатами, шаблонами, группами тестов и дополнительными инструментами оптимизации.

2. Какие данные обрабатываются

  • Настройки стратегий: параметры бектестов, шаблоны, выбранные активы, условия, настройки сетки, выхода из сделки и иные данные, введённые пользователем.
  • Результаты бектестов: история запусков, показатели, результаты, группы тестов, локальные отчёты и данные, необходимые для их отображения.
  • Данные текущей сессии Veles: идентификатор пользователя, сведения о тарифе, балансе, лимитах и доступных возможностях — только в объёме, необходимом для отображения функций расширения и выполнения выбранного действия.
  • Диагностические записи: локальный журнал действий и ошибок, необходимый для формирования bug-report по инициативе пользователя.
  • Данные ИИ-оптимизатора: только при явном выборе пользователем этой функции — API-ключ выбранного провайдера, выбранная модель, запрос пользователя, настройки стратегии и результаты, необходимые для выполнения оптимизации.

3. Где хранятся данные

Настройки, шаблоны, история запусков, результаты, локальные журналы и настройки ИИ-оптимизатора хранятся локально в профиле браузера пользователя с использованием механизмов Chrome Storage и IndexedDB.

Veles Helper не отправляет эти локальные данные на серверы разработчика.

4. Взаимодействие с Veles Finance

Когда пользователь сам запускает бектест, импортирует стратегию, получает данные, создаёт или запускает бота, расширение выполняет соответствующее действие через открытую авторизованную вкладку Veles Finance.

В Veles передаются только данные, необходимые для выбранного пользователем действия: например, параметры стратегии, период бектеста, выбранный актив или настройки создания бота. Обработка этих данных платформой Veles регулируется её собственной политикой конфиденциальности.

Расширение не читает, не сохраняет и не передаёт разработчику пароль пользователя или сессионные cookies Veles.

5. ИИ-оптимизатор и сторонние ИИ-провайдеры

ИИ-оптимизатор является дополнительной функцией и используется только после явного выбора пользователя. Пользователь может выбрать один из поддерживаемых провайдеров: OpenRouter, AITunnel или ClaudeHub.

При использовании ИИ-оптимизатора выбранному провайдеру могут передаваться API-ключ, запрос пользователя, описание и параметры оптимизируемой стратегии, а также данные, необходимые для подготовки и оценки вариантов оптимизации. API-ключ используется только для авторизации у выбранного пользователем провайдера и хранится локально в браузере.

Обработка данных выбранным ИИ-провайдером регулируется политикой конфиденциальности соответствующего провайдера. Пользователь самостоятельно принимает решение о выборе провайдера и использовании своего API-ключа.

6. Локальный ИИ-агент

При явном выборе режима локального ИИ-агента расширение может взаимодействовать с локальным сервисом на устройстве пользователя через адрес localhost или 127.0.0.1. Такие данные не передаются разработчику Veles Helper.

7. Передача данных третьим лицам

Veles Helper не продаёт и не передаёт пользовательские данные рекламным сетям, аналитическим платформам или брокерам данных.

Передача данных возможна только напрямую:

  • в Veles Finance — при выполнении действия, выбранного пользователем;
  • выбранному пользователем ИИ-провайдеру — при использовании ИИ-оптимизатора;
  • локальному ИИ-агенту на устройстве пользователя — при выборе такого режима.

8. Bug-report

Bug-report создаётся только после нажатия пользователем кнопки «Скачать bug-report». Файл формируется локально и не отправляется разработчику автоматически. Пользователь самостоятельно решает, кому и когда передать этот файл.

9. Управление и удаление данных

Пользователь может удалять отдельные элементы истории и результаты через интерфейс расширения. Для полного удаления локальных данных можно удалить расширение или очистить его данные в настройках браузера Chrome.

Пользователь может прекратить передачу данных внешнему ИИ-провайдеру, не используя ИИ-оптимизатор и удалив сохранённый API-ключ из настроек расширения.

10. Защита данных

Передача данных во внешние сервисы выполняется по защищённым HTTPS-соединениям. Доступ к данным Veles осуществляется только в контексте открытой пользователем авторизованной вкладки Veles Finance.

11. Изменение политики

Политика может обновляться при изменении функций расширения или способов обработки данных. Актуальная версия всегда публикуется на этой странице.
